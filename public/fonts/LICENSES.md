# Fontes

Todas as fontes são distribuídas sob a SIL Open Font License 1.1 (https://openfontlicense.org)
e foram baixadas do Fontsource (subconjunto *latin*, que cobre o português).

| Arquivo | Família | Autor |
|---|---|---|
| BebasNeue-Regular.ttf | Bebas Neue | Dharma Type |
| PinyonScript-Regular.ttf | Pinyon Script | Nicole Fally |
| CourierPrime-Regular.ttf, CourierPrime-Bold.ttf | Courier Prime | Quote-Unquote Apps |
| Caveat-Regular.ttf | Caveat | Impallari Type |
| Inter-Regular.ttf, Inter-SemiBold.ttf | Inter | Rasmus Andersson |

Os mesmos arquivos TTF são usados pela interface (@font-face) e pelo PDF da revista
(@react-pdf/renderer, que não carrega Google Fonts via CSS).
